# p1
* Markdown là ngôn ngữ đánh dấu đơn giản, dùng các ký hiệu ngắn để định dạng văn bản. HTML sử dụng các thẻ mở và đóng nên thường có nhiều ký tự hơn khi tạo cùng một định dạng.
* AI xử lý văn bản bằng cách chia nội dung thành các đơn vị gọi là Token. Markdown thường giúp giảm số ký tự định dạng, từ đó có thể giảm số Token cần xử lý, tiết kiệm chi phí và tăng tốc độ phản hồi.

**Markdown ngắn gọn hơn, dễ đọc và dễ chỉnh sửa. Tuy nhiên, số Token thực tế còn phụ thuộc vào bộ mã hóa Token và nội dung cụ thể, nên Markdown không phải lúc nào cũng sử dụng ít Token hơn HTML**

# So sánh Markdown và HTML trong hệ thống GreenTech

| Tiêu chí | Markdown | HTML |
|---|---|---|
| Số lượng ký tự | Ít, ngắn gọn | Nhiều hơn |
| Cách viết | Dùng ký hiệu đơn giản | Dùng thẻ mở và đóng |
| Độ dễ đọc | Dễ đọc, dễ sửa | Khó đọc hơn khi có nhiều thẻ |
| Sử dụng Token | Thường tiết kiệm Token định dạng | Có thể tốn nhiều Token hơn |
| Tốc độ xử lý AI | Có thể nhanh hơn | Phụ thuộc độ phức tạp |
| Khả năng định dạng | Phù hợp nội dung cơ bản | Linh hoạt, tùy chỉnh cao |
| Ứng dụng | Prompt AI, tài liệu hướng dẫn | Website, giao diện phức tạp |

## Đánh giá

Markdown phù hợp với hệ thống GreenTech vì cú pháp đơn giản,
dễ đọc, dễ chỉnh sửa và thường giảm lượng ký tự định dạng.

HTML phù hợp khi cần xây dựng giao diện website phức tạp.
